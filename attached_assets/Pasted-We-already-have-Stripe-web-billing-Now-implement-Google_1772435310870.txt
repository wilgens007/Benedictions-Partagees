T003: Add POST /api/billing/google/verify
- Create server/googleBillingRoutes.ts
- Route: POST /api/billing/google/verify
- Body: { productId, purchaseToken }  (NO userId)
- Requires requireUser
- Reads:
  GOOGLE_SERVICE_ACCOUNT_KEY (JSON string or base64 JSON)
  GOOGLE_PLAY_PACKAGE_NAME (e.g. com.benedictionspartagees.bp)
- Uses Google Play Android Publisher API to verify subscription purchase token:
  Prefer googleapis library:
    import { google } from "googleapis";
    const auth = new google.auth.GoogleAuth({
      credentials: parsedServiceAccount,
      scopes: ["https://www.googleapis.com/auth/androidpublisher"],
    });
    const androidpublisher = google.androidpublisher({ version: "v3", auth });
    Call purchases.subscriptionsv2.get with packageName, token (and subscriptionId if needed by library version),
    OR fallback to purchases.subscriptions.get (v3) depending on available endpoint.
- Verify purchase is active (not canceled/expired):
  Determine expiryTimeMillis / lineItems expiryTime etc.
  If expiry is in the future -> active.
- Update user (req.user.id):
    isPremium=true
    premiumSource="google"
    premiumExpiresAt=expiry date
    googlePurchaseToken=purchaseToken
    premiumSince if empty set to now
- Return { success: true, isPremium: true, premiumExpiresAt }.
- Register this router in server/index.ts under /api/billing/google.

Also return clean errors:
- 401 if not logged in
- 400 if missing fields
- 403/422 if token invalid
- 500 if API misconfigured
