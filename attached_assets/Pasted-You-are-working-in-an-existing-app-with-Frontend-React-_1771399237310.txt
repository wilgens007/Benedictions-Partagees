- Determine priceId based on plan env vars
- Create Stripe customer if user doesn't have one
- Create Stripe Checkout Session:
   - mode: 'subscription'
   - line_items: [{ price: priceId, quantity: 1 }]
   - success_url: APP_URL + '/dashboard?checkout=success'
   - cancel_url: APP_URL + '/pricing?checkout=cancel'
   - metadata: { userId }
Return: { url } for client redirect

2) POST /api/billing/create-portal-session
Auth required.
- Create Stripe Billing Portal session using stripe_customer_id
Return: { url }

3) POST /api/stripe/webhook
Use raw body middleware for webhook verification.
Handle events:
- checkout.session.completed
- customer.subscription.created
- customer.subscription.updated
- customer.subscription.deleted
For each event:
- Identify userId via metadata.userId OR via customer lookup in DB
- Upsert into subscriptions table:
   - status
   - stripe_customer_id
   - stripe_subscription_id
   - stripe_price_id
   - current_period_end
   - cancel_at_period_end
- Set users.is_premium = true if status in ('active','trialing')
- Set users.is_premium = false otherwise
- Set users.premium_since when becoming premium

Add logging and error handling.
On webhook signature failure: return 400.
