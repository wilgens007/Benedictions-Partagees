- Users can opt-in to daily notifications.
- When today’s devotion is CREATED (not “exists”), send ONE push notification to all subscribers.
- Must be reliable, DST-aware (America/New_York), and safe across restarts.

Requirements:
1) Install web-push and use VAPID keys via env vars:
   - VAPID_PUBLIC_KEY
   - VAPID_PRIVATE_KEY
   - VAPID_SUBJECT (mailto: contact@benedictionspartagees.org)
2) Create DB table push_subscriptions:
   - id
   - endpoint UNIQUE
   - p256dh
   - auth
   - language (optional)
   - createdAt
   - auto-delete subscriptions that return 404/410 on send
3) Add Service Worker at /sw.js (must be root-scoped) to receive push and show notification.
4) Add UI on /devotion (or settings):
   - Button: “Enable Daily Notifications”
   - Optional: “Disable Notifications”
   - iOS note: push works only when installed as PWA (“Add to Home Screen”)
5) Add API routes:
   - GET /api/push/vapid-public-key -> { publicKey }
   - POST /api/push/subscribe -> save subscription
   - POST /api/push/unsubscribe (optional)
   - POST /api/push/send-today (internal, protected by X-CRON-SECRET)
6) Trigger sending:
   - In POST /api/devotion/generate: if status=created, call send-today once.
7) Default notification payload:
   - title: “BP — Devotion du jour”
   - body: “Le verset et la méditation d’aujourd’hui sont prêts. Touchez pour lire 🙏”
   - url: “/devotion”
8) Logging:
   - subscribe/unsubscribe counts
   - send success/fail counts
   - verbose errors (no silent fails)
